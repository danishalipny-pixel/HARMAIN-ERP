## 🌟 Executive Overview

**HARMAIN ERP** is a premium, enterprise-grade Hajj, Umrah & Travel Agency Management System engineered specifically for licensed pilgrimage operators, travel conglomerates, and government quota holders.

Built under a luxury Islamic-inspired brand aesthetic featuring **Deep Emerald Green (`#0A4D3C`)**, **Luxury Gold (`#D4AF37`)**, **Pure White**, and **Dark Charcoal**, HARMAIN ERP automates the entire pilgrimage lifecycle—from initial pilgrim passport registration and biometric visa submission to airline seat allotments, Makkah/Madinah courtyard hotel bed allocations, airport transfers, and final multi-currency accounting reconciliation.

## 💰 Actual Accounting Logic & Currency Support

HARMAIN ERP enforces real double-entry accounting formulas without hardcoded numbers:
- **Total Booking Revenue** = `Selling Price Per Pax × Number of Passengers`
- **Total Direct Costs** = `Air Tickets Cost + Makkah Hotel Cost + Madinah Hotel Cost + Ground Transport + Visa Fees + Ziyarat/Catering + Sub-Agent Commission`
- **Gross Profit** = `Total Booking Revenue - Total Direct Costs`
- **Net Profit** = `Gross Profit - Operating Expenses (Salaries, Rent, Marketing, Utilities)`
- **Outstanding Balance** = `Total Selling Price - Total Customer Paid Installments`
- **Supported Currencies**: `PKR` (Base Ledger), `SAR` (Saudi Operations), and `USD` (International Settlements) with real-time conversion across all views.

## 🚀 Setup & Installation Instructions

### 1. Prerequisites
- **Node.js** v18+ (tested on Node v20 & v24)
- **npm** v9+

### 2. Clone Repository
```bash
git clone https://github.com/danishalipny-pixel/HARMAIN-ERP.git
cd HARMAIN-ERP
```

### 3. Install Dependencies
```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Build frontend assets
npm run build
cd ..
```

### 4. Start Application
```bash
# Launch unified server from root
npm start
```
The application will launch at:
👉 **`http://localhost:5000`**
